# collaflow-monorepo
CollaFlow — 高性能协同脑图框架，支持 MCP 协议与私有化部署。Monorepo 结构，包含 CollaCore（协同服务）、CollaMind（脑图引擎）、CollaMarkdown（协作文档）等模块。
